# 러너 게임 기본 코드 (블록코딩)

## MakeCode 블록 구성

```
┌─────────────────────────┐
│ 무한반복 (forever)        │
│                         │
│  만약 [버튼 A 눌림] 이면  │
│    시리얼 한줄 쓰기 "jump"   │
│  끝                      │
│                         │
│  일시중지 (ms) 30        │
└─────────────────────────┘
```

## MakeCode JavaScript (블록과 1:1 대응)

```javascript
basic.forever(function () {
    if (input.buttonIsPressed(Button.A)) {
        serial.writeLine("jump")
    }
    basic.pause(30)
})
```

## MakeCode 에디터에서 만드는 방법

1. https://makecode.microbit.org/ 접속
2. 새 프로젝트 만들기
3. 아래 블록을 순서대로 배치:

### 블록 배치 순서

1. **기본 > 무한반복** 블록을 가져옴
2. **논리 > 만약~이면** 블록을 무한반복 안에 넣음
3. **입력 > 버튼 A 눌림** 블록을 만약 조건에 넣음
4. **시리얼 > 시리얼 한줄 쓰기** 블록을 만약 안에 넣음
   - 텍스트를 "j"로 변경
5. **기본 > 일시중지(ms)** 블록을 무한반복 맨 아래에 넣음
   - 값을 30으로 변경

> ⚠️ "시리얼" 카테고리가 안 보이면 **고급 > 시리얼** 에서 찾을 수 있습니다.
